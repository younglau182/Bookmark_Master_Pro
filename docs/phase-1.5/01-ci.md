Title: CI: run npm test and npm run validate:manifest on push & PR

## Background

The project currently relies on contributors running validation commands locally. A lightweight CI workflow should make the existing safety checks visible on every branch push and every pull request into `main`.

## Scope

Add a GitHub Actions workflow that installs the project with Node 20.x and runs the existing test and manifest validation commands.

## Acceptance criteria

- Add `.github/workflows/ci.yml` on Node 20.x.
- Trigger on push to any branch and PR to main.
- Cache npm dependencies.
- Fail build on `npm test` or `npm run validate:manifest` failure.

## Out of scope

- deploy
- release
- lint setup

## Note

This file is only a spec. Do NOT create `.github/workflows/ci.yml` in this PR.
